# Module 6 矩阵乘法 short report

## 基准测试

在 `module-6` 下运行：

```powershell
D:\miniconda3\envs\course_env\python.exe benchmark_task1.py --threads 8 --device both
python plot_results.py
```

`benchmark_task1.py` 对比 NumPy CPU、PyTorch CPU、PyTorch CUDA 三种方法，
统一使用 `float32`、相同随机输入和 8 个 CPU 线程。GPU 输入在计时前已驻留
显存，因此计时包含核函数启动、输出分配和同步，不包含主机到显存传输。
脚本先做三路数值一致性检查，再进行预热、轮换顺序计时，并把中位耗时写入
`results.json`。GPU 不可用时可加 `--device cpu` 只跑 CPU 版本。
`plot_results.py` 仅从该 JSON 重建两张报告图。

## 编译

在 `module-6/report` 下运行：

```powershell
latexmk -xelatex -interaction=nonstopmode -halt-on-error report.tex
```

最终 PDF 为 `module-6/report/report.pdf`，共 3 页。
