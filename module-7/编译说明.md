# Module 7 PPO short report

## 检查与训练

在 `module-7` 目录下运行：

```powershell
D:\miniconda3\envs\course_env\python.exe test_ppo.py
D:\miniconda3\envs\course_env\python.exe train_ppo.py --episodes 500
D:\miniconda3\envs\course_env\python.exe plot_results.py
```

`train_ppo.py` 保存全部 500 个回合的原始 return、9 回合滑动平均和汇总统计
到 `results.json`，不打开渲染窗口。`plot_results.py` 只读取该文件生成报告图。
本机使用 `gymnasium==1.2.1` 和 `pygame-ce==2.5.8` 运行与 starter 相同的
CartPole 接口；提交的 `code/ppo.py` 仍保留题目要求的 `import gym` 写法。

## 编译

在 `module-7/report` 目录下运行：

```powershell
latexmk -xelatex -interaction=nonstopmode -halt-on-error report.tex
```

最终 PDF 为 `module-7/report/report.pdf`，共 3 页。
