# Module 5 BCG / BrowseComp short report

## Build

Run from `module-5/report`:

```powershell
latexmk -xelatex -interaction=nonstopmode -halt-on-error report.tex
```

The report uses the same letter-paper template and Times typography as
Modules 1--4. The system diagram is embedded in `report.tex`, so no external
figure files are required.

## Submission

Upload `ML5_2510124204_submission.pdf` to the Gradescope **Short Assignment**
channel. The short assignment requires only the PDF; the source is kept in
`report/` for reproducibility and does not need to be uploaded separately.

The report is a design document rather than a BrowseComp run. It does not
claim measured accuracy, token counts, or a completed benchmark.
