# Module 4 Robotics short report

## Build

Run from `module-4/report`:

```powershell
latexmk -xelatex -interaction=nonstopmode -halt-on-error report.tex
```

The report uses the same Letter-paper template and Times typography as Modules
1--3. TikZ figures are embedded in `report.tex`, so no external image files are
required.

## Submission

Upload `ML4_2510124204_submission.zip` to the Gradescope **Short Assignment**
channel. The archive contains:

- `report.pdf`
- `report.tex`
- `reference.bib`
- `config.tex`
- `template22.sty`

The report is a design document rather than a simulator experiment. It does not
claim measured robot results.
