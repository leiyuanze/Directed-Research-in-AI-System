# Module 3 论文：修改与编译说明

## 文件

- `report.tex` — 论文正文，主要修改对象
- `reference.bib` — 参考文献（BibTeX）
- `config.tex` — 课程模板的宏包与格式设置，一般不用改
- `template22.sty` — 课程 LaTeX 模板，不要改
- `report.pdf` — 当前编译结果

## 环境

TeX Live 2025（`xelatex`、`bibtex`、`latexmk` 均已可用）。
论文是纯英文排版，推荐用 XeLaTeX 编译（与当前配置一致）。

## 推荐编译方式

在 `report` 目录下执行：

```powershell
cd 'D:\leiyuanze\0courses\大二上\系统实践1\Directed-Research-in-AI-System\module-3\report'
latexmk -xelatex -interaction=nonstopmode report.tex
```

- 成功时生成或更新 `report.pdf`
- 修改 `.bib` 或新增引用后，`latexmk` 会自动重跑 BibTeX
- 清理中间文件（保留 PDF）：`latexmk -c`
- 全部清理（含 PDF）：`latexmk -C`

如果编译报 `Unable to open "report.pdf"`，说明 PDF 正在被阅读器
（如 WPS、Edge）打开。先关闭阅读器再编译。

## 手动分步编译

不依赖 `latexmk` 时：

```powershell
xelatex -interaction=nonstopmode report.tex
bibtex report
xelatex -interaction=nonstopmode report.tex
xelatex -interaction=nonstopmode report.tex
```

如果正文出现 `[?]` 或编译日志里有 `undefined citation`，通常是编译次数不够。

## 常见修改

1. 标题、作者：`report.tex` 顶部的 `\title{...}`、`\author{...}`
2. 章节：`\section{...}`、`\subsection{...}`、`\paragraph{...}`
3. 引用：
   - 括号引用：`\citep{sutton1981toward}`
   - 句中引用：`\citet{stahl2015observing}`
4. 新增文献：在 `reference.bib` 加 BibTeX 条目，再在正文引用
5. 页数：正文到 `\bibliographystyle{plainnat}` 前为止；参考文献不计入页数
6. 作者名：在 `\author{...}` 中，当前为拼音 `Yuanze Lei`
